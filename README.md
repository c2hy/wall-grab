# WallGap - Windows 主题图片管理器

WallGap 是一款专门用于提取 Windows 聚焦壁纸的工具。

## 📥 下载安装

1. 访问 [GitHub Releases 页面](https://github.com/your-username/wall-grab/releases)
2. 下载最新版本的 `WallGap-Setup-x.x.x.exe` 安装包
3. 双击运行安装程序，按照提示完成安装
4. 安装完成后，在开始菜单或桌面找到 WallGap 图标启动应用

## 🚀 使用指南

### 快速开始

1. **启动应用**: 运行 WallGap 后，应用会自动扫描 Windows 聚焦壁纸
2. **浏览图片**: 应用以全屏模式显示图片，支持鼠标滚轮缩放
3. **导航图片**: 
   - 使用左右箭头按钮切换图片
   - 或使用键盘左右方向键导航
4. **保存图片**: 点击右上角的保存按钮（💾），选择保存位置

## 🛠️ 技术实现

- **框架**: Flutter 3.9.2+
- **语言**: Dart
- **文件操作**: dart:io 库
- **UI组件**: Material Design 3
- **文件选择**: file_picker 插件
- **平台支持**: Windows 10/11
